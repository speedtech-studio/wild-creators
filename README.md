WILD CREATOR — SEA & LAND V2

This version follows the approved visual direction:
- mission panel on the left
- more immersive Land World + Sea World
- student drawing becomes the animated creature
- lesson-focused selectable adjectives
- Describe → Compare → Justify
- pupil chooses Sea or Land before release
- creature collection strip
- tap creature to see its English profile
- fullscreen classroom/projector mode

Lesson adjective bank currently included:
big, small, tall, short, long, strong, fast, slow, heavy, light, colourful, friendly

Comparatives:
bigger, smaller, taller, shorter, faster, slower, heavier, lighter

This build stores creatures locally in the browser for testing. It does not yet replace the Supabase realtime classroom version.
