# Wild Creator V1 🌿🐾

An interactive Year 4 English learning prototype for the **Wild Adventure** lesson.

## Learning journey
Imagine → Draw → Scan/Upload → Bring to Life → Explore → Describe → Compare → Justify → Complete

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the main branch and `/ (root)`, then Save.

## Important: 3D status
V1 includes a functional drawing upload/camera workflow and an interactive animated **3D-style digital habitat**. It does **not** falsely claim to reconstruct a real 3D mesh from a drawing.

A true image-to-3D service should be added through a secure backend in V2. Do not expose a private API key in `script.js`.

## Assessment focus
The creature-making experience supports language production:
- descriptive adjectives
- `It has...`
- `It can...`
- comparative adjectives
- `I like my creature because...`

The visual quality of the drawing is not the English assessment criterion.
